# Binary Parser

Ce programme permet la conversion d'un nombre entier en binaire, ou inversement.
- Le fichier binary_to_decimal permet la conversion d'un nombre binaire vers un nombre entier.
- Le fichier decimal_to_binary, à l'inverse, permet de convertir un nombre décimal en nombre binaire.
- Le fichier main demande à l'utilisateur quel convertisseur il souhaite utiliser ; il lui demande également d'entrer un nombre et effectue la conversion selon ce qu'avait pu choisir l'utilisateur précédemment.
